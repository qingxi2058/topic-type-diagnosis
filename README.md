# 选题类型诊断

不是帮你想选题，是帮你在做之前判断这个选题做出来是涨粉还是攒收藏。

小红书内容只有两种根本属性：收藏型（用户存起来以后查）和涨粉型（用户想看你的下一篇）。这两种内容的运营逻辑完全不同。如果你想涨粉，一直发收藏型内容会让收藏看起来好看但粉丝不动。

这个 Skill 帮你在做内容之前搞清楚这件事。

## 这个 Skill 适合谁

- 发了很多内容但粉丝不涨的博主
- 收藏率很高但老是不涨粉，不知道为什么
- 选题想了很多但不知道哪个更值得做
- 想涨粉但不知道应该做什么类型的内容

## 它能做什么

- 用四个维度判断选题是收藏型还是涨粉型
- 检查是否命中三类扑街黑名单
- 匹配你的目标（涨粉/收藏），给出值得做/改方向/不建议做三选一结论
- 给出收藏型和涨粉型的不同打法建议
- 解释为什么"只有收藏没有粉丝"是正常现象，以及怎么改

## 典型使用场景

- "这个选题能涨粉吗？"
- "为什么我的内容收藏很多但粉丝不涨"
- "这几个选题哪个更值得做"
- "我想专门涨粉，应该做什么类型的内容"
- "做了很多但账号粉丝一直不动"

## 推荐输入格式

```text
1. 选题方向（一句话）
2. 你想要的结果：涨粉 / 收藏 / 两者均衡
3. 账号方向（如：AI工具测评 / 职场效率 / 生活方式）
```

## 输出长什么样

默认输出：

1. 类型判断（收藏型 / 涨粉型 / 两者均衡）+ 判断依据
2. 黑名单检查结果
3. 结论（值得做 / 改方向再做 / 不建议做）
4. 如需改方向：具体改法
5. 对应类型的打法建议
